## 1. 项目是什么

- **项目名称**:`banksys_szai4`(银行营销认购预测 Web 应用)
- **一句话目标**:基于银行营销历史数据,提供「数据分析交互页」与「在线预测系统」,预测客户是否会认购定期存款产品,让营销人员点选输入即可获得是否认购的判断依据。
- **使用者/受益者**:银行营销人员、数据分析师;本项目为课程项目,由学生维护。
- **核心功能**:
  - 数据分析交互页面:数据概览、分布探索、类别-目标交叉分析、筛选联动图表。
  - 离线训练:从 `data/train.csv` 训练 scikit-learn 模型,产出模型产物与评估报告。
  - 在线预测系统:用户在网页通过点选/下拉/数字输入客户信息,得到认购概率与"是否认购"结论。
- **输入/数据**:
  - `data/train.csv`:22,500 行 × 22 列(21 特征 + `subscribe` 标签),正例率 13.1%,无缺失值。
  - `data/test.csv`:7,500 行 × 21 列(仅特征,无标签,打分集)。
  - UCI 公开教学数据(银行营销),无敏感信息,约 3.7MB,**提交进 Git**。
  - **模型产物(`models/`)不进 Git**,训练可重复生成(见第 3 节目录地图)。

| 格式/静态检查 | ruff | 课程标准 |

| CI/CD | GitHub Actions | 课程标准(PR→CI→合并→CD) |

## 4. 质量门槛

| 类型 | 本项目标准 |
|---|---|
| 格式检查 | `ruff format --check .` |
| 静态检查 | `ruff check .` |
| 单元测试 | `pytest` |
| 覆盖率 | ≥ 80%(核心逻辑) |
| 构建 | `docker build` 成功(CI 跑,本地不强制) |
| 业务/模型指标 | 训练门禁:holdout AUC ≥ 0.80,不达标以非零码退出;`test.csv` 预测文件生成成功 |

## 5. 不变约束

- 密钥、密码、私钥、Token **绝不写进代码或文档**,只进 GitHub Secrets / 环境变量。
- 数据集(公开教学数据,~3.7MB)**提交进 Git**;模型产物(`models/`)**不进 Git**,Docker 构建时训练生成,保证模型与镜像绑定、无陈旧产物。
- `main` 分支受保护,日常开发必须走 feature 分支 + PR。
- CI 红灯不合并。
- **端口策略**:主机端口首选 8888,被占用时在预留区间 8888-8899 内自动顺延空闲端口(共享服务器,05 规范 §4);容器内 8501(Streamlit 默认)。

## 6. 部署/CI 占位符取值

| 占位符 | 本项目取值 | 说明 |
|---|---|---|
| `<APP>` | `banksys_szai4` | 镜像名/容器名 |
| `<DEPLOY_DIR>` | `/opt/banksys_szai4` | 服务器部署目录 |
| `<PORT>` | `8888` | 首选主机端口(被占用则回退) |
| `<PORT_MAX>` | `8899` | 预留端口区间上限 |
| 容器内端口 | `8501` | Streamlit 默认端口 |
| `<PYVER>` | `3.11` | Python 版本 |
| `<HEALTHCHECK>` | `/_stcore/health` | Streamlit 官方健康端点,返回 `ok` |
| `<SSH_USER>` | 待配置(GitHub Secret) | 部署用户 |
| `<SSH_HOST>` | 待配置(GitHub Secret) | 服务器公网 IP 或域名 |
